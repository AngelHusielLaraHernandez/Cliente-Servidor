\section{Prueba local}

el puerto se recibe desde la línea de comandos y se utiliza \texttt{htons()} para convertirlo al orden de bytes de la red.

\end{lstlisting}

\section{Conexión al servidor del profesor}
Ahora bien, para esta prueba se ejecutó el cliente apuntando al servidor \texttt{132.248.59.6}, en el puerto 4898. Se escribió mi nombre desde el teclado y se recibió la respuesta de registro exitoso. También se ejecutó \texttt{date} en la misma terminal para mostrar la fecha y hora.
\begin{lstlisting}[style=output]
./cliente_examen_parcial 132.248.59.6 4898
date
\end{lstlisting}
